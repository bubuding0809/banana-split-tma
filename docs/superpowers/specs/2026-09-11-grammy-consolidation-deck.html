Why now

Bot API 10.1 (June 2026) added rich messages. 10.3 (Aug 2026) added embedded buttons inside them.

telegraf 4.16.3 is the latest on npm and stops at Bot API 7.x. No sendRichMessage, no <tg-button>. grammy 1.46.0 has all of it typed.

Two libraries today

apps/lambdatelegraf 4.16.3Bare client. 4 files

telegraf's framework half is unused. It is an HTTP client with types.

Options

A · grammy Api everywhere chosen

Swap ctx.teleBot to grammy's standalone client. Retire telegraf + dead dep. Typed rich calls. One lib, one version.

B · raw shim on telegraf rejected

callApi("sendRichMessage") with hand-typed params. Smallest diff, but two libs stay and every future Bot API field is hand-maintained.

Goal and non-goals

One Telegram library, at a version that exposes rich messages. Every message renders identically afterward.

Non-goals: sending any rich message · changing text or buttons · touching apps/bot feature code · retiring MarkdownV2 escaping
